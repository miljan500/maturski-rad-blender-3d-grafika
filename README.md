# Blender 3D grafika

## Autor

- **Autor:** \[Miljan Milivojević\]
- **Škola:** Negotinska gimnazija
- **Godina:** 2023.

## Korišćeni alati

- **Program:** Blender

## Sadržaj

U okviru rada obrađene su sledeće oblasti:

- Upoznavanje sa programom Blender i njegovim korisničkim interfejsom
- Rad sa editorima i scenama
- Objekti i načini rada: Object Mode i Edit Mode
- Selekcija objekata i elemenata
- Transformacije objekata: pomeranje, rotiranje i skaliranje
- Navigacija kroz 3D prostor i podešavanje kamere
- Organizacija objekata pomoću kolekcija i Outliner-a
- Rad sa mrežastim (Mesh) objektima
- Osnovne operacije modelovanja:
  - Subdivide
  - Loop Cut
  - Extrude
- Rad sa temenima (Vertices)
- Podešavanje svojstava objekata
- Modifikatori i materijali
- Priprema scene i renderovanje
